# MCP 던전 로그라이크

> MCP(Model Context Protocol) 기반 텍스트 던전 탐험 로그라이크 게임

---

## 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 장르 | 텍스트 기반 턴제 던전 크롤러 로그라이크 |
| 플랫폼 | CLI / MCP 클라이언트 (Claude Desktop 등) |
| 언어 | Python 3.11+ |
| DB | SQLite (로컬) |
| 버전 | **v6.9** (Phase 1~4 완료, QA 완료) |

---

## 핵심 특징

- **영구 죽음**: 죽으면 처음부터 다시 시작 (소울은 유지!)
- **5층 응축 구조**: 짧고 긴장감 있는 던전 탐험
- **절차적 생성**: 매번 다른 던전 구조 (Random Walk 알고리즘)
- **풍부한 콘텐츠**: 30종 몬스터, 70+ 아이템, 31종 축복, 10종 듀오
- **6개 직업**: 전사/궁수/마법사/도적/성기사/사신
- **MCP 기반**: AI 클라이언트와 자연스러운 상호작용
- **메타 프로그레션**: 소울로 영구 업그레이드, 업적, 직업 해금
- **저장/불러오기**: 5개 슬롯 지원, 자동 저장

## 설치 및 실행

### 필수 요구사항

- Python 3.11 이상
- [Claude Desktop](https://claude.ai/download) (또는 다른 MCP 클라이언트)

### 1단계: 프로젝트 설치

```bash
# 저장소 클론
git clone https://github.com/dongmin1213/mcp-dungeon.git
cd mcp-dungeon

# 의존성 설치
pip install mcp pydantic aiosqlite
```

### 2단계: Claude Desktop 설정

Claude Desktop 설정 파일을 열어 MCP 서버를 등록합니다.

**설정 파일 위치:**
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`
- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`

**설정 내용 추가:**
```json
{
  "mcpServers": {
    "mcp-dungeon": {
      "command": "python",
      "args": ["C:/path/to/mcp-dungeon/mcp-dungeon-server/server.py"],
      "env": {}
    }
  }
}
```

> `C:/path/to/mcp-dungeon` 부분을 실제 프로젝트 경로로 변경하세요.

### 3단계: 게임 시작

1. Claude Desktop 재시작
2. 새 대화 시작
3. "던전 게임 시작해줘" 또는 "start_game" 입력

## 플레이 가이드

### 기본 명령어

| 명령 | 설명 |
|------|------|
| "게임 시작" | 새 게임 시작 또는 저장된 게임 이어하기 |
| "상태 확인" | 현재 HP, 골드, 위치 등 확인 |
| "북쪽으로 이동" | 던전 탐험 (north/south/east/west) |
| "공격" | 전투 중 기본 공격 |
| "인벤토리" | 아이템 확인 |
| "도움말" | 게임 도움말 보기 |

### 문제 해결

| 문제 | 해결 방법 |
|------|----------|
| MCP 서버 연결 안됨 | 경로 확인, Claude Desktop 재시작 |
| Python 버전 오류 | Python 3.11+ 설치 확인 |
| 모듈 없음 오류 | `pip install mcp pydantic aiosqlite` 재실행 |
