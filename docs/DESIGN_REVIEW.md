## 2. 주요 개선 사항 (v6.8)

### 2.1 저주 시스템 완전 가동 ✅

**이전 문제**: 저주 아이템이 정의만 있고 효과 없음
**해결**: 전투 흐름에 저주 효과 통합

```
작동하는 저주 효과:
- 턴당 데미지 (damage_per_turn)
- 도망 불가 (no_flee)
- 휴식 회복 감소 (rest_heal_mult)
- 포션 회복 감소 (potion_heal_mult)
- 상점 가격 증가 (shop_price_mult)
- 받는 데미지 증가 (damage_taken_mult)
```

**게임플레이 영향**:
- 저주 아이템이 진짜 "저주"가 됨
- "저주의 주인" 시너지가 의미 있어짐
- 리스크/리워드 선택 추가

---

### 2.2 AI 지능 향상 ✅

**이전 문제**: AI가 플레이어 HP를 모름 (항상 풀피 가정)
**해결**: 실제 HP 비율 전달, 저HP 시 공격적 전환

```
AI 개선 내용:
- 플레이어 HP 30% 이하 → 50% 확률로 강타
- 더 위협적인 전투 경험
- 포션 사용 타이밍이 중요해짐
```

**게임플레이 영향**:
- 빈사 상태에서 긴장감 증가
- 회복 아이템 관리 전략 필요
- "버틸 수 있을까?" 순간 증가

---

### 2.3 포션 슬롯 제한 확인 ✅

**이전 판단**: 미구현으로 오판
**실제**: 이미 `systems/shop.py`에 구현되어 있었음

```
포션 시스템:
- 최대 3개 슬롯 제한 ✅
- 구매 시 체크 ✅
- 자원 긴장감 유지 ✅
```
