## 1. 핵심 공식

### 1.1 데미지 계산
```python
damage = max(1, ATK - DEF)           # 최소 1 데미지
critical_damage = damage * 1.5       # 크리티컬 (15% 확률)
skill_damage = damage * multiplier + flat_bonus
```

### 1.2 레벨업
```python
required_exp = level * 100           # Lv.2 = 100, Lv.3 = 200 ...
# 레벨업 보상: HP+10, MP+5, ATK+2, DEF+1, 전체회복
```

### 1.3 도망
```python
flee_chance = 50 + (player_agi - monster_agi) * 2  # 30~80% 범위
# 보스전 도망 불가, 연막탄 100% 성공
```

### 1.4 방어
```python
defended_damage = damage * 0.5       # 받는 데미지 50% 감소
```
