## 설계 원칙

### 사기 빌드의 정의
```
사기 빌드 = 강함 + 명확한 약점 + 플레이 스타일 강제
```

| 요소 | 설명 |
|------|------|
| 강함 | 특정 상황에서 압도적 (x3~x5 효과) |
| 약점 | 명확한 카운터 존재 (원샷, 특정 속성 등) |
| 스타일 강제 | 빌드마다 다른 플레이 요구 |

### 나쁜 예시 vs 좋은 예시

**나쁜 예시 (그냥 강한 것):**
```
흡혈 30% + 가시 반사 = 데미지 반사하고 회복
→ 고인물 반응: "그래서? 그냥 좀 강한 거 아님?"
```

**좋은 예시 (사기 빌드):**
```
흡혈자 + 가시 갑옷 + 도발 = "무한 탱커"
→ 적이 나만 때림 + 맞으면 반사 + 반사로 회복
→ 이론상 무적
→ 단, 보스 강타에 원샷 위험 = 긴장감 유지
→ 플레이: 보스 강타 턴에 방어 필수
```

| 1C.4 밸런스 수정 | ✅ | `systems/synergy.py` - apply_execute, apply_lifesteal |

### 적용된 밸런스 수정
1. **보스 즉사 불가**: execute_threshold 효과가 보스에게 적용되지 않음
2. **흡혈 상한**: 턴당 최대 HP의 30%까지만 흡혈 가능 (무한 회복 방지)
3. **사기 빌드 약점 유지**:
   - 무한 탱커: 보스 강타에 원샷 위험, 흡혈 상한으로 버스트 데미지에 취약
   - 저주의 주인: 저주 아이템 3개 필요 (초반 약함)
   - 원소의 화신: 같은 속성 3개 필요 (아이템 운 의존)

### 체크리스트
- [x] 사기 빌드 없이도 클리어 가능한가? → 기존 장비/축복 조합으로 충분
- [x] 사기 빌드가 "자동 승리"가 아닌가? → 보스 즉사 불가, 흡혈 상한
- [x] 모든 직업이 사기 빌드 접근 가능한가? → 장비 기반이라 직업 무관

| 던전 마스터 (5층) | 3페이즈 | Phase 1(마법사/화염약점) → Phase 2(전사/냉기약점) → Phase 3(최종/약점없음) | 페이즈별 속성 준비 |

### 보스 기믹 설계

**1층 - 슬라임 킹:**
```
기믹: 분열
- HP 30% 이하 → 미니 슬라임 2마리 소환
- 미니 슬라임 생존 시 본체 매턴 HP 10% 회복
- 전략: 본체 집중 vs 미니 먼저 처리
```

**2층 - 여왕 거미:**
```
기믹: 거미줄 + 새끼 소환
- 매 3턴마다 거미줄 → 다음 턴 행동 불가
- 새끼 거미 지속 소환 (최대 3마리)
- 전략: 거미줄 턴에 방어, 새끼 관리
```

**3층 - 오크 대족장:**
```
기믹: 분노 스택
- 피격 시마다 분노 +1 (ATK +5%)
- HP 50% 이하 → 광폭화 (ATK x2, DEF 0)
- 전략: 빠른 처치 vs 광폭화 후 역이용
```

**4층 - 뱀파이어 로드:**
```
기믹: 흡혈 + 박쥐 변신
- 공격 데미지의 50% 회복
- HP 30% 이하 → 박쥐 변신 (회피 80%, 3턴)
- 전략: 변신 중 스킬 아껴두기
```

**5층 - 던전 마스터:**
```
기믹: 3페이즈 전환
- Phase 1 (100~70%): 마법사 - 원거리 공격, 화염 약점
- Phase 2 (70~30%): 전사 - 근접 강타, 냉기 약점
- Phase 3 (30~0%): 최종 - 모든 속성 저항, 패턴 랜덤
- 전략: 페이즈별 속성 무기 준비
```
